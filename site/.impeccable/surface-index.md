# Surface brief — sOMP landing (index)

## Scope + mode

Landing page for sOMP at somp.gobrowse.dev. Mode: Persuade — visitor
(SWE-agent terminal user evaluating sandboxing) decides to try the one-line

## Direction contract

THESIS: The page IS a protection-relay panel, not a page about one. The
product's mechanism — protection states as physical switch positions,
fail-closed refusal as an open breaker — is demonstrated in the first
viewport with three working breakers (STRICT/STANDARD/OFF) driving pilot
lamps and a mono readout. Category default refused: hero-metric stats,
icon-card grids, gradient glow hero.

OWN-WORLD: Dark steel panel ground, hairline wiring traces, engraved-cap
labels (tracked small caps), tabular mono readouts, one amber lamp accent;
green/red reserved for state semantics (governed/refused). Chakra Petch
display (squared instrument letterforms), system sans body, ui-monospace
for code and data. Raised breakers carry offset+blur shadow; everything
else is flat steel with 1px borders.

STORY: Visitor understands in one viewport (subagents leave the machine,
mine stay mine), believes via the working panel + honest-limits section,
acts via the one-line install command one keystroke away.

FIRST VIEWPORT: Left — headline, one-line mechanism sub, install command
box with copy key, secondary docs link. Right — the relay panel: three
breakers (STRICT engaged), lamp bank, readout strip showing `somp doctor`
evidence. Primary action sits under the command box, not in nav.

FORM: Single long page, alternating dense panel passages and quiet steel
(ikebana donation: active emptiness). Breaker interaction is the one
authored motion; reveals elsewhere are still. Sections: mechanism wiring
diagram (SVG linework) → install procedure (numbered, sewing-pattern
donation) → levels as breaker slots → honesty (UNPROVEN) → FAQ → close.
